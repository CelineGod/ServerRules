# Contributing to ServerRules 🤝

Thank you for considering contributing to ServerRules! Here are a few simple guidelines to help you get started.

## How Can You Contribute?

### 1. Reporting Bugs 🐛
If you find a bug or issue, please open an **Issue** on GitHub and include:
- A clear description of the issue.
- Steps to reproduce the bug.
- Your server version (e.g., Paper 1.20.1) and Java version.
- Any relevant error logs from your server console.

### 2. Suggesting Features 💡
Have an idea for new rule categories, GUI customization options, or new commands? Feel free to open an **Issue** to discuss it!

### 3. Submitting Pull Requests 📥
If you want to contribute code directly:
1. **Fork** the repository.
2. Create a new branch for your feature or bugfix (`git checkout -b feature/amazing-feature`).
3. Commit your changes with clear and descriptive messages (`git commit -m "Add new feature"`).
4. Push to your branch (`git push origin feature/amazing-feature`).
5. Open a **Pull Request** and briefly describe what you changed and why!

---
Thank you for helping make ServerRules better! 🚀
