# Security Policy

## Supported Versions

Only the latest release of ServerRules is currently supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability or exploit within ServerRules, please **do not** open a public issue. 

Instead, please report it privately:
- Contact the maintainer directly via **GitHub Private Vulnerability Reporting** (if enabled), or
- Send an email to: `suppcelinegod@gmail.com`

You will receive a response within **48 hours**. Thank you for helping keep this project secure!
